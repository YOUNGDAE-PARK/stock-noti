# 주식 의견 판단 AI 개선 요구사항 정리

## 1. 개선 목표

현재 `src/services/judge.js`에 구현된 주식 판단 AI는 다음 요소를 기반으로 의견을 제시하고 있다.

- 사용자의 보유 이유
- 사용자의 리스크 키워드
- 뉴스 내용
- 주가 반응
- 구조적 리스크
- 최종 판단 신호

현재 구조는 단순 뉴스 요약형 AI보다 우수하지만, 실제 투자 판단에 활용하려면 다음 방향으로 개선이 필요하다.

> **뉴스를 잘 읽는 AI에서, 포트폴리오 리스크까지 관리하는 투자 판단 AI로 고도화해야 한다.**

---

## 2. 현재 전략의 장점

현재 시스템에서 유지해야 할 장점은 다음과 같다.

### 2.1 사용자 맞춤형 판단 구조

사용자가 입력한 `investment_thesis`, 즉 보유 이유를 판단 기준으로 삼는 구조는 유지한다.

AI는 단순히 뉴스가 좋은지 나쁜지를 보는 것이 아니라, 해당 뉴스가 사용자의 기존 투자 논리를 강화하는지 훼손하는지를 판단해야 한다.

### 2.2 리스크 키워드 기반 감지

사용자가 직접 입력한 리스크 키워드를 활용하는 방식도 유지한다.

예를 들어 사용자가 특정 기업에 대해 다음과 같은 리스크를 우려하고 있다면, 관련 이벤트 발생 시 중요도를 높여야 한다.

| 리스크 예시 | 의미 |
|---|---|
| 경쟁사 진입 | 시장 점유율 하락 가능성 |
| 특허 만료 | 독점력 약화 가능성 |
| 유상증자 | 주주가치 희석 가능성 |
| 임상 실패 | 바이오 기업의 핵심 가치 훼손 |
| 규제 조사 | 영업 지속성 또는 평판 훼손 |

### 2.3 시장 반응을 함께 보는 구조

뉴스만 보고 판단하지 않고, 실제 주가 반응을 함께 보는 방향은 적절하다.

다만 현재처럼 단순히 당일 주가 등락률만 보는 방식은 개선이 필요하다.

### 2.4 판단 근거 제공

리포트 하단의 “근거(AI Reason)” 섹션에서 판단 이유를 제공하는 방식은 유지한다.

단, 앞으로는 찬성 근거뿐 아니라 반대 근거, 불확실성, 다음 확인 포인트까지 함께 제시해야 한다.

## 3. 가장 먼저 개선해야 할 핵심 문제

### 3.1 고정 수익률 기준 제거

현재 전략에서 가장 위험한 부분은 다음과 같은 고정 기준이다.

| 현재 판단 방식 | 문제점 |
|---|---|
| 호재 뉴스 후 주가가 1% 이상 하락하면 재료 소멸 판단 | 종목별 변동성 차이를 반영하지 못함 |
| 호재 뉴스 후 주가가 상승하면 추매검토 | 시장 전체 상승이나 섹터 상승 덕분일 수 있음 |
| 악재 뉴스 후 주가 하락 시 매도검토 | 이미 알려진 악재이거나 일시적 반응일 수 있음 |

특히 -1%라는 단일 기준은 대형주, 소형주, 바이오, 성장주, 경기민감주 모두에 동일하게 적용하기 어렵다.

### 개선 방향

단순 주가 등락률 대신 아래 요소를 함께 판단해야 한다.

| 판단 요소 | 설명 |
|---|---|
| 종목 수익률 | 해당 종목의 당일 또는 특정 기간 수익률 |
| 시장 수익률 | 코스피, 코스닥, S&P500, 나스닥 등 기준지수 수익률 |
| 섹터 수익률 | 반도체, 바이오, 금융, 2차전지 등 업종 수익률 |
| 초과수익률 | 종목 수익률이 시장과 섹터 대비 얼마나 좋은지 |
| 최근 변동성 | 해당 종목의 평소 움직임 대비 현재 반응이 큰지 |
| 거래량 변화 | 평소 대비 거래량이 증가했는지 |
| 거래대금 변화 | 실제 수급이 의미 있게 들어왔는지 |
| 장중 흐름 | 상승 후 밀렸는지, 하락 후 회복했는지 |

## 4. Sell on News 판단 개선

### 현재 문제

현재 시스템은 호재 뉴스가 나왔는데 주가가 하락하면 “재료 소멸” 또는 “선반영”으로 판단할 수 있다.

하지만 실제 시장에서는 다음 가능성도 함께 고려해야 한다.

| 가능성 | 설명 |
|---|---|
| 진짜 재료 소멸 | 뉴스가 이미 가격에 반영되어 차익실현 발생 |
| 시장 전체 하락 | 개별 기업 문제가 아니라 시장 약세 영향 |
| 섹터 조정 | 해당 업종 전체가 약세인 상황 |
| 단기 차익실현 | 단기 매물 출회 후 재상승 가능성 |
| 실적 발표 후 지연 반응 | 호재가 며칠에 걸쳐 반영될 가능성 |
| 기대치 미달 | 뉴스 자체는 좋지만 시장 기대에는 못 미침 |

### 개선 요구사항

Sell on News 판단은 아래 조건들이 복합적으로 확인될 때만 내려야 한다.

| 조건 | 설명 |
|---|---|
| 뉴스는 명확히 긍정적이어야 함 | 단순 중립 뉴스는 제외 |
| 사용자의 보유 이유를 강화해야 함 | thesis와 관련 없는 호재는 신호 약화 |
| 시장/섹터 대비 주가 반응이 약해야 함 | 단순 하락률이 아니라 상대 성과를 봐야 함 |
| 거래량 증가가 동반되어야 함 | 실제 차익실현 물량인지 확인 |
| 뉴스 전 주가 선반영 여부를 봐야 함 | 최근 며칠 또는 몇 주간 급등 여부 확인 |
| 밸류에이션 부담을 확인해야 함 | 이미 비싼 구간이면 재료 소멸 가능성 증가 |
| AI Reason에 선반영 가능성을 명시해야 함 | 사용자에게 판단 근거를 투명하게 제공 |

### 판단 방향

| 상황 | 권장 신호 |
|---|---|
| 호재 + 섹터 대비 강한 상승 + 거래량 증가 | 추매검토 가능 |
| 호재 + 절대 주가는 하락했지만 섹터도 급락 | 보유 또는 관찰 |
| 호재 + 섹터 대비 약세 + 거래량 급증 + 선반영 정황 | 비중축소 |
| 호재 + 재무 영향 불명확 + 주가 급등 | 관찰 |
| 호재 + 밸류에이션 과열 + 현재 비중 과다 | 보유 또는 비중축소 |

## 5. 밸류에이션 판단 레이어 추가

### 현재 문제

현재 시스템은 좋은 뉴스가 나오면 추매검토로 기울 가능성이 있다.

하지만 실제 투자에서는 다음 구분이 필요하다.

> **좋은 뉴스와 좋은 매수 기회는 다르다.**

좋은 회사, 좋은 뉴스라도 이미 주가가 너무 비싸면 추가 매수는 부적절할 수 있다.

### 개선 요구사항

최종 판단 전에 밸류에이션 판단 레이어를 추가한다.

### 확인해야 할 항목

| 항목 | 설명 |
|---|---|
| PER | 이익 대비 주가 수준 |
| PBR | 순자산 대비 주가 수준 |
| PSR | 매출 대비 주가 수준 |
| EV/EBITDA | 기업가치 대비 영업현금창출력 |
| PEG | 성장률 대비 밸류에이션 |
| 역사적 밸류에이션 | 과거 평균 대비 현재가 비싼지 |
| 동종업계 비교 | 경쟁사 대비 프리미엄 또는 할인 여부 |
| 최근 주가 선반영 | 뉴스 전 이미 많이 올랐는지 |
| 기대치 반영 여부 | 컨센서스나 시장 기대가 이미 높았는지 |

### 밸류에이션 위험 등급

밸류에이션은 아래처럼 구분한다.

| 등급 | 의미 |
|---|---|
| 낮음 | 추가 상승 여력이 상대적으로 있음 |
| 보통 | 과열도 저평가도 아닌 상태 |
| 높음 | 추매에는 부담스러운 상태 |
| 알 수 없음 | 데이터 부족으로 판단 보류 |

### 판단 원칙

밸류에이션 위험이 높으면 아무리 좋은 뉴스가 나와도 즉시 추매검토를 내면 안 된다.

이 경우에는 다음 중 하나를 우선한다.

| 상황 | 권장 신호 |
|---|---|
| 뉴스 좋음 + 밸류 부담 높음 | 보유 |
| 뉴스 좋음 + 밸류 부담 높음 + 주가 급등 | 비중축소 |
| 뉴스 좋음 + 밸류 데이터 부족 | 관찰 |
| 뉴스 좋음 + 밸류 적정 + 비중 여유 있음 | 추매검토 가능 |

## 6. 포트폴리오 비중 관리 추가

### 현재 문제

현재 판단은 종목 단위에 집중되어 있다.

하지만 실제 투자 판단은 항상 포트폴리오 전체 관점에서 이루어져야 한다.

같은 뉴스라도 사용자의 보유 비중에 따라 판단이 달라져야 한다.

### 추가해야 할 사용자 설정값

| 항목 | 설명 |
|---|---|
| 현재 종목 비중 | 포트폴리오 내 해당 종목 비중 |
| 목표 종목 비중 | 사용자가 원하는 적정 비중 |
| 최대 종목 비중 | 초과하면 추매 제한 |
| 현재 섹터 비중 | 특정 업종 쏠림 여부 |
| 최대 섹터 비중 | 섹터 집중 위험 관리 |
| 현금 비중 | 추가 매수 가능 여부 |
| 위험 성향 | 보수형, 중립형, 공격형 |
| 투자 기간 | 단기, 중기, 장기 |
| 최대 손실 허용폭 | 손실 관리 기준 |

### 판단 원칙

추매검토는 아래 조건을 모두 고려해야 한다.

| 조건 | 설명 |
|---|---|
| thesis 강화 | 사용자의 보유 이유가 강화되어야 함 |
| 가격 반응 양호 | 시장/섹터 대비 긍정적 반응 필요 |
| 밸류에이션 부담 낮음 | 과열 상태가 아니어야 함 |
| 현재 비중 적정 | 이미 너무 많이 보유 중이면 추매 제한 |
| 섹터 비중 적정 | 특정 업종에 과도하게 쏠리지 않아야 함 |
| 현금 여유 있음 | 추가 매수 가능성이 있어야 함 |

### 예시 판단

| 상황 | 기존 판단 | 개선 판단 |
|---|---|---|
| 호재 + 주가 상승 | 추매검토 | 현재 비중이 목표 비중 이하일 때만 추매검토 |
| 호재 + 주가 상승 + 현재 비중 과다 | 추매검토 가능성 | 보유 또는 비중축소 |
| 호재 + 섹터 전체 과열 | 추매검토 가능성 | 관찰 또는 보유 |
| thesis 훼손 + 손실 허용폭 초과 | 보유 가능성 | 매도검토 |

## 7. 리스크 키워드를 리스크 구조로 확장

### 현재 문제

현재 `risk_keywords`가 단순 키워드 매칭에 가깝다면 누락 위험이 크다.

예를 들어 사용자가 “특허 만료”를 리스크로 입력했더라도 뉴스에는 아래처럼 표현될 수 있다.

| 표현 | 실제 의미 |
|---|---|
| 제네릭 출시 | 특허 독점력 약화 |
| 독점권 종료 | 특허 만료와 유사 |
| 복제약 허가 | 매출 감소 가능성 |
| 약가 인하 압력 | 수익성 악화 가능성 |
| 특허 소송 패소 | 기술적 진입장벽 훼손 |

### 개선 요구사항

리스크 키워드를 단순 단어 목록이 아니라 리스크 카테고리로 확장한다.

### 추천 리스크 분류

| 상위 리스크 | 하위 이벤트 예시 |
|---|---|
| 경쟁 리스크 | 신규 진입, 가격 인하, 점유율 하락, 대체재 등장 |
| 규제 리스크 | 허가 지연, 조사 착수, 과징금, 판매중지 |
| 재무 리스크 | 유상증자, 전환사채, 현금 고갈, 이자비용 증가 |
| 기술 리스크 | 임상 실패, 특허 무효, 품질 문제 |
| 지배구조 리스크 | 횡령, 배임, 회계 이슈, 감사의견 문제 |
| 수급 리스크 | 보호예수 해제, 대주주 매도, 기관 이탈 |
| 사업 리스크 | 주요 고객 이탈, 수주 취소, 원가 상승 |
| 매크로 리스크 | 금리 상승, 환율 급변, 원자재 가격 상승 |

### 판단 원칙

사용자가 입력한 리스크 키워드와 정확히 일치하지 않아도, 의미상 같은 리스크라면 감지해야 한다.

## 8. 뉴스 출처 신뢰도 반영

### 현재 문제

모든 뉴스가 같은 신뢰도를 갖는 것은 아니다.

공식 공시와 익명 루머를 동일하게 판단하면 안 된다.

### 출처별 신뢰도 기준

| 출처 | 신뢰도 |
|---|---|
| DART 공시 | 최상 |
| 거래소 공시 | 최상 |
| 회사 IR 자료 | 높음 |
| 실적 발표 자료 | 높음 |
| 주요 경제지 기사 | 중상 |
| 증권사 리포트 | 중상 |
| 일반 언론 재인용 기사 | 중간 |
| 블로그, 커뮤니티 | 낮음 |
| SNS, 익명 루머 | 매우 낮음 |

### 판단 원칙

| 상황 | 권장 신호 |
|---|---|
| 출처 신뢰도 높음 + 구조적 악재 | 비중축소 또는 매도검토 |
| 출처 신뢰도 높음 + thesis 강화 | 추매검토 가능 |
| 출처 신뢰도 낮음 + 호재성 루머 | 관찰 |
| 출처 신뢰도 낮음 + 주가 급등 | 관찰 또는 경고 |
| 출처 신뢰도 낮음 + 악재성 루머 | 즉시 매도보다 관찰 또는 알림 |

### 추가 요구사항

AI Reason에는 반드시 출처 신뢰도를 표시한다.

예시 표현:

```text
출처 신뢰도: 높음
판단 근거: 회사 공식 공시 기반 정보이므로 신뢰도가 높습니다.
```

또는:

```text
출처 신뢰도: 낮음
판단 근거: 공식 공시가 아닌 언론 보도 또는 루머성 정보이므로 추가 확인이 필요합니다.
```

## 9. 뉴스 유형별 판단 기준 세분화

### 현재 문제

현재는 호재/악재 중심 판단에 가깝다.

하지만 실제 투자 판단에서는 뉴스 유형별로 중요하게 봐야 할 항목이 다르다.

### 뉴스 유형 분류

| 뉴스 유형 | 핵심 판단 기준 |
|---|---|
| 실적 발표 | 매출, 영업이익, 순이익, 가이던스, 일회성 요인 |
| 수주·계약 | 계약 규모, 기간, 마진, 취소 가능성 |
| 임상·바이오 | 임상 단계, endpoint 충족 여부, 안전성, 시장 규모 |
| 신제품 | 매출 기여 시점, 경쟁 제품, 가격 결정력 |
| 규제·소송 | 금전적 손실, 영업 지속성 영향 |
| 유상증자·CB·BW | 희석률, 자금 사용처, 재무 안정성 |
| M&A | 인수가격, 시너지, 재무 부담 |
| 자사주·배당 | 일회성인지 지속 가능한 주주환원인지 |
| 대주주·임원 매매 | 내부자 신뢰도 변화 여부 |
| 보호예수 해제 | 단기 수급 부담 |
| 공장 증설 | 실제 수요와 가동률 확인 |
| 공급계약 해지 | 매출과 신뢰도 훼손 여부 |

### 판단 예시

| 뉴스 | 바로 판단하지 말고 확인할 것 |
|---|---|
| 대규모 수주 | 계약 규모가 매출 대비 어느 정도인지 |
| 실적 개선 | 일회성 이익인지 반복 가능한 이익인지 |
| 임상 성공 | 몇 상인지, 주요 평가변수를 충족했는지 |
| 유상증자 | 운영자금인지 성장투자인지, 희석률은 얼마인지 |
| 자사주 매입 | 실제 소각인지 단순 취득인지 |
| 배당 확대 | 일회성인지 지속 가능한 정책인지 |

## 10. 구조적 리스크 판단 개선

### 현재 문제

현재 전략은 구조적 리스크가 있는 기업에 대해 보수적으로 접근한다.

이 방향은 좋지만, “구조적 리스크가 있으니 호재에도 미온적이면 비중축소”는 너무 단순할 수 있다.

### 개선 방향

중요한 것은 다음이다.

> 해당 호재가 구조적 리스크를 실제로 완화하는 호재인지 구분해야 한다.

### 판단 기준

| 상황 | 권장 신호 |
|---|---|
| 구조적 리스크 존재 + 호재가 리스크와 무관 | 보유 또는 비중축소 |
| 구조적 리스크 존재 + 호재가 리스크를 직접 완화 | 관찰 또는 추매검토 가능 |
| 구조적 리스크 존재 + 주가만 급등, 펀더멘털 개선 없음 | 비중축소 |
| 구조적 리스크 존재 + 공식 공시 기반 실적 개선 확인 | 보유 또는 추매검토 가능 |
| 구조적 리스크 존재 + 추가 악재 발생 | 매도검토 |

### 예시

| 기존 리스크 | 새 뉴스 | 개선 판단 |
|---|---|---|
| 특허 만료 | 단기 실적 호조 | 보유 또는 비중축소 |
| 특허 만료 | 차세대 제품 허가 | 관찰 또는 추매검토 가능 |
| 경쟁사 진입 | 단기 주가 급등 | 비중축소 |
| 경쟁사 진입 | 시장 점유율 방어 확인 | 보유 또는 관찰 |
| 재무 리스크 | 유상증자 발표 | 비중축소 또는 매도검토 |
| 재무 리스크 | 차입금 상환, 현금흐름 개선 | 관찰 또는 보유 |

## 11. 고위험 자산 판단 강화

### 대상

다음 종목은 일반 종목보다 보수적으로 판단해야 한다.

| 유형 | 이유 |
|---|---|
| 바이오 벤처 | 임상 결과와 자금 조달 리스크가 큼 |
| 신규 상장주 | 적정 가치와 수급 안정성 확인이 어려움 |
| 적자 성장주 | 금리와 자금 조달 환경에 민감 |
| 테마주 | 뉴스와 무관한 수급 변동 가능성 큼 |
| 소형주 | 유동성 부족과 변동성 확대 가능성 |
| 관리종목 위험 기업 | 상장 유지 리스크 존재 |

### 판단 원칙

고위험 자산은 좋은 뉴스가 나와도 바로 추매검토를 내리지 않는다.

우선 아래 요소를 확인한다.

| 확인 항목 | 설명 |
|---|---|
| 뉴스의 지속성 | 일회성인지 반복 가능한지 |
| 재무 영향 | 실제 매출과 이익에 연결되는지 |
| 자금 조달 리스크 | 추가 유상증자 가능성 |
| 유동성 | 거래량이 충분한지 |
| 변동성 | 과도한 단기 급등락이 있는지 |
| 출처 신뢰도 | 공식 공시인지 루머인지 |

### 권장 신호

| 상황 | 권장 신호 |
|---|---|
| 고위험 자산 + 호재 + 재무 영향 불명확 | 관찰 |
| 고위험 자산 + 호재 + 공식 공시 + 지속성 확인 | 보유 또는 추매검토 가능 |
| 고위험 자산 + 주가 급등 + 출처 불명확 | 관찰 또는 비중축소 |
| 고위험 자산 + 악재 발생 | 비중축소 또는 매도검토 |

## 12. “관찰” 신호의 역할 강화

### 현재 문제

관찰 신호가 단순히 중립적인 상태로 쓰이면 안 된다.

관찰은 “애매함”이 아니라 “추가 확인이 필요한 의미 있는 상태”여야 한다.

### 관찰 신호 정의

```text
관찰은 투자 thesis와 관련된 변화가 감지되었으나,
재무 영향, 출처 신뢰도, 가격 반응, 지속성 중 하나 이상이 불충분하여
즉각적인 매수·매도 판단보다 추가 확인이 필요한 상태다.
```

### 관찰로 보내야 하는 경우

| 상황 | 이유 |
|---|---|
| 뉴스는 좋지만 출처 신뢰도 낮음 | 루머 가능성 |
| 호재지만 재무 영향 불명확 | 과대해석 방지 |
| 주가는 급등했지만 거래량 부족 | 신뢰도 낮은 상승 |
| 실적 개선이 일회성일 가능성 | 지속성 확인 필요 |
| 시장 전체 급락일 | 개별 종목 반응 해석 어려움 |
| 공시 전 언론 보도 | 공식 확인 필요 |
| 밸류에이션 데이터 부족 | 추매 판단 보류 |
| 포트폴리오 비중 정보 부족 | 행동 판단 제한 |

## 13. 최종 신호 정의 개선

현재 신호 체계는 유지하되, 의미를 더 명확하게 정의한다.

### 13.1 매도검토

| 항목 | 내용 |
|---|---|
| 의미 | 강한 악재 또는 thesis 훼손 발생 |
| 사용 상황 | 회복 어려운 펀더멘털 훼손, 구조적 악재, 규제·소송·재무 리스크 |
| 주의점 | 단순 주가 하락만으로 매도검토를 내리지 않음 |
| 사용자 행동 | 즉시 보유 근거 재검토, 손절 또는 청산 검토 |

### 13.2 비중축소

| 항목 | 내용 |
|---|---|
| 의미 | 리스크 증가 또는 기대수익 감소 |
| 사용 상황 | 재료 소멸, 밸류에이션 과열, 목표 비중 초과, 구조적 우려 |
| 주의점 | 전량 매도보다 일부 위험 축소에 가까운 신호 |
| 사용자 행동 | 일부 차익실현 또는 보유 비중 조정 검토 |

### 13.3 보유

| 항목 | 내용 |
|---|---|
| 의미 | 기존 투자 논리를 유지할 수 있는 상태 |
| 사용 상황 | 큰 변화 없음, thesis 유지, 가격 반응 중립 |
| 주의점 | 무조건 낙관이 아니라 기존 판단 유지 |
| 사용자 행동 | 기존 계획 유지 |

### 13.4 추매검토

| 항목 | 내용 |
|---|---|
| 의미 | 추가 매수를 검토할 만한 조건이 일부 또는 대부분 충족된 상태 |
| 사용 상황 | thesis 강화, 가격 반응 양호, 밸류 부담 낮음, 비중 여유 있음 |
| 주의점 | 즉시 매수 지시가 아님 |
| 사용자 행동 | 추가 매수 가능성 검토 |

### 13.5 관찰

| 항목 | 내용 |
|---|---|
| 의미 | 의미 있는 변화가 있으나 아직 행동 판단에는 정보가 부족한 상태 |
| 사용 상황 | 출처 불확실, 재무 영향 불명확, 지속성 미확인 |
| 주의점 | 단순 중립이 아니라 추가 확인 필요 상태 |
| 사용자 행동 | 후속 공시, 실적, 수급, 가격 흐름 확인 |

## 14. AI Reason 출력 구조 개선

현재 “근거(AI Reason)”는 반드시 유지하되, 아래 구조로 확장한다.

### 필수 포함 항목

| 항목 | 설명 |
|---|---|
| 최종 판단 | 매도검토, 비중축소, 보유, 추매검토, 관찰 |
| 판단 요약 | 한 문장으로 핵심 이유 설명 |
| thesis 영향 | 사용자의 보유 이유를 강화했는지 훼손했는지 |
| 긍정 근거 | 판단에 긍정적으로 작용한 요소 |
| 부정 근거 | 판단에 부정적으로 작용한 요소 |
| 가격 반응 해석 | 주가, 시장, 섹터 대비 반응 |
| 밸류에이션 판단 | 저평가, 적정, 과열, 데이터 부족 |
| 포트폴리오 영향 | 현재 비중과 목표 비중 관점 |
| 출처 신뢰도 | 공시, 언론, 루머 등 |
| 불확실성 | 아직 확인되지 않은 부분 |
| 다음 확인 포인트 | 사용자가 이후 확인해야 할 내용 |

### 출력 예시

```text
최종 판단: 관찰

판단 요약:
신규 수주 뉴스는 사용자의 해외 매출 확대 thesis와 부합하지만,
계약 마진과 실적 반영 시점이 불명확하여 즉각적인 추매보다는 관찰이 적절합니다.

thesis 영향:
보유 이유를 일부 강화합니다.

긍정 근거:
- 수주 뉴스가 기존 투자 thesis와 관련 있음
- 계약 규모가 최근 매출 대비 의미 있을 가능성 있음

부정 근거:
- 계약 마진이 공개되지 않음
- 최근 주가가 이미 단기 급등함
- 현재 밸류에이션 부담이 높을 수 있음

가격 반응:
- 종목은 상승했으나 섹터 대비 초과수익은 제한적입니다.

포트폴리오 영향:
- 현재 비중이 목표 비중에 근접해 있다면 추매는 신중해야 합니다.

출처 신뢰도:
- 공식 공시 기반이면 높음
- 단순 언론 보도라면 추가 확인 필요

불확실성:
- 실제 이익 기여도와 납품 기간이 확인되지 않았습니다.

다음 확인 포인트:
- 계약 세부조건
- 다음 분기 수주잔고 반영 여부
- 기관·외국인 수급 지속성
```

## 16. 백테스트 및 성과 검증 기능 추가

### 문제

AI 판단이 실제로 유효한지 검증하지 않으면 전략 품질을 개선하기 어렵다.

### 추적해야 할 지표

| 지표 | 설명 |
|---|---|
| 신호별 1일 수익률 | 단기 반응 확인 |
| 신호별 5일 수익률 | 단기 추세 확인 |
| 신호별 20일 수익률 | 중기 방향성 확인 |
| 추매검토 후 최대낙폭 | 잘못된 추매 신호 검증 |
| 비중축소 후 기회손실 | 너무 빨리 판 신호 검증 |
| 매도검토 후 회복률 | 과도한 매도 판단 검증 |
| 관찰 후 방향성 | 관찰 신호의 유용성 확인 |
| 거래비용 반영 성과 | 잦은 매매로 인한 손실 확인 |
| 섹터별 성과 | 특정 업종 편향 확인 |
| 시가총액별 성과 | 대형주·소형주 차이 확인 |
| 출처별 정확도 | 공시, 언론, 루머별 신뢰도 검증 |

### 개선 방향

각 신호가 실제 이후 수익률과 어떤 관계가 있었는지 기록하고, 판단 기준을 지속적으로 보정한다.

## 19. 최종 요구사항 요약

Codex는 기존 `judge.js`의 판단 로직을 다음 방향으로 개선해야 한다.

```text
1. 단순 뉴스 감성 판단을 지양한다.
2. 사용자의 보유 이유와 리스크 키워드를 핵심 기준으로 유지한다.
3. 단순 주가 등락률이 아니라 시장·섹터 대비 반응을 본다.
4. -1% 같은 고정 기준은 제거한다.
5. Sell on News 판단은 선반영, 거래량, 밸류에이션, 상대수익률을 함께 본다.
6. 추매검토는 좋은 뉴스만으로 내리지 않는다.
7. 추매검토에는 밸류에이션, 현재 비중, 목표 비중, 섹터 비중을 반영한다.
8. 리스크 키워드는 단순 단어가 아니라 리스크 카테고리로 확장한다.
9. 뉴스 출처 신뢰도를 반드시 반영한다.
10. 뉴스 유형별로 판단 기준을 다르게 적용한다.
11. 구조적 리스크가 있는 기업은 호재가 해당 리스크를 완화하는지 별도로 판단한다.
12. 고위험 자산은 좋은 뉴스가 나와도 관찰을 우선할 수 있다.
13. 관찰 신호는 정보 부족 또는 지속성 검증 필요 상태로 명확히 정의한다.
14. AI Reason에는 긍정 근거뿐 아니라 부정 근거와 불확실성을 포함한다.
15. 최종 판단에는 신뢰도 등급을 함께 표시한다.
16. 신호별 사후 수익률을 기록해 백테스트와 성능 개선이 가능하도록 한다.
```

## 20. 최종 방향성

현재 시스템은 좋은 출발점이다.

다만 앞으로는 아래 방향으로 고도화해야 한다.

| 기존 | 개선 |
|---|---|
| 뉴스 중심 판단 | 뉴스 + 가격 + 밸류 + 포트폴리오 통합 판단 |
| 단순 호재/악재 분류 | thesis 강화/훼손 중심 판단 |
| 고정 등락률 기준 | 변동성·시장·섹터 보정 기준 |
| 종목 단독 판단 | 포트폴리오 비중 반영 |
| 찬성 근거 중심 | 찬성·반대·불확실성 동시 제시 |
| 추매/축소 중심 | 관찰과 신뢰도까지 포함한 단계적 판단 |

최종 목표는 다음과 같다.

> **사용자가 왜 이 종목을 보유하는지, 지금 뉴스가 그 이유를 강화하는지 훼손하는지, 현재 가격과 비중에서 행동할 가치가 있는지를 함께 판단하는 AI로 개선한다.**
